## 📊 技术栈更新

### 新增依赖
```
lightrag-hku==1.4.11    # HKUDS 官方 LightRAG
sentence-transformers==5.2.3  # 本地 Embedding 模型
torch==2.10.0           # PyTorch
transformers==5.3.0     # HuggingFace Transformers
```

### 核心配置
```python
# LightRAG + Sentence Transformers
from lightrag import LightRAG, QueryParam
from lightrag.utils import EmbeddingFunc
from sentence_transformers import SentenceTransformer

embedding_model = SentenceTransformer('all-MiniLM-L6-v2')
embedding_func = EmbeddingFunc(
    embedding_dim=384,
    func=lambda texts: embedding_model.encode(texts).tolist()
)
lightrag = LightRAG(
    working_dir='./rag_data',
    embedding_func=embedding_func
)
```

## 💡 经验与洞察

### 技术洞察
1. **LightRAG 版本选择**:
   - PyPI 版 `lightrag==0.1.0b6` API 不完整
   - GitHub HKUDS 版 `lightrag-hku==1.4.11` 功能完整但文档少
   - 建议：直接使用 GitHub 版，但需要阅读源码

2. **Embedding 模型选择**:
   - OpenAI API：准确率高，有成本
   - Sentence Transformers：免费，准确率可接受
   - Phase 2 建议：本地模型优先

3. **测试驱动开发**:
   - 先写测试脚本再开发功能
   - 快速验证，快速迭代
   - 测试报告作为交付物之一

### 产品洞察
1. **市场定位关键**:
   - 不做大而全的企业级 RaaS
   - 聚焦个人开发者细分市场
   - CLI-first 符合开发者习惯

2. **差异化策略**:
   - 本地优先（数据隐私）
   - Agent 原生集成（非通用 API）
   - 渐进式演进（本地→云端）
