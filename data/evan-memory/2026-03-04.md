## 模型信息获取规则 (新增)

### 数据源
**URL**: https://raw.githubusercontent.com/BerriAI/litellm/main/model_prices_and_context_window.json

### 用途
- 获取所有模型供应商的完整模型列表
- 获取模型定价信息
- 获取上下文长度限制
- 获取模型功能支持情况

### 优势对比
| 数据源 | 覆盖范围 | 更新频率 | 准确性 |
|--------|---------|---------|--------|
| **LiteLLM** | 200+ 供应商，1000+ 模型 | 每日更新 | ⭐⭐⭐⭐⭐ |
| OpenRouter API | 50+ 供应商，200+ 模型 | 实时更新 | ⭐⭐⭐⭐ |
| 手动维护 | 有限 | 不定期 | ⭐⭐⭐ |

### LiteLLM 覆盖的供应商 (部分)
- OpenAI, Anthropic, Google, Meta, Mistral
- AWS Bedrock, Azure, GCP, Ollama
- DeepSeek, Qwen, Cohere, xAI, Perplexity
- 以及 180+ 其他供应商

### 使用示例
```bash
# 获取完整模型列表
curl -s https://raw.githubusercontent.com/BerriAI/litellm/main/model_prices_and_context_window.json

# 解析特定供应商
cat model_prices.json | jq 'keys | map(select(startswith("gpt")))'
```
